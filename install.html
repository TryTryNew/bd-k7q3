孟加拉 App 安裝說明

三語讀經＋孟加拉語生活用語。存到手機後，在孟加拉沒有網路也能看、也能聽。

用手機相機掃這個 QR code，或打開網址：
trytrynew.github.io/bd-k7q3
⚠️ 一定要在台灣、有網路的時候先裝好。第一次會下載大約 20 MB（經文和錄音），建議用 Wi-Fi。

iPhone 用 Safari

  1. 用 Safari 打開網址（LINE 裡的連結請按右下角「⋯」→「用 Safari 開啟」；Chrome 在 iPhone 上不能裝）。
  2. 按畫面下方的 分享 按鈕（方框加向上的箭頭）。
  3. 往下滑，按 加入主畫面，再按右上角 加入。
  4. 回到主畫面，點新出現的 孟加拉 圖示打開。
  5. 等首頁顯示 ✓ 已可離線使用 才算完成，下載時不要關掉。

Android 用 Chrome

  1. 用 Chrome 打開網址。
  2. 按右上角 ⋮，選 安裝應用程式 或 加到主畫面。
  3. 從主畫面的 孟加拉 圖示打開。
  4. 等首頁顯示 ✓ 已可離線使用 才算完成。
出發前檢查（每個人都做一次）
  1. 打開 飛航模式。
  2. 從主畫面打開「孟加拉」，首頁還在。
  3. 進「三語讀經」，按一節旁邊的 ▶，有聲音。
  4. 進「生活用語」，按一句的 ▶ 唸，有聲音。
  5. 都 OK 就關掉飛航模式，完成！

常見問題

  1. 沒有聲音？ 先確認手機不是靜音（iPhone 左側的切換鍵），音量調大。
  2. 一直停在「正在下載」？ 連上 Wi-Fi，保持畫面打開幾分鐘。
  3. iPhone 很久沒打開，資料不見了？ iPhone 可能會清掉很久沒用的資料。出發前一週再打開一次；在孟加拉也偶爾打開一下。
  4. 有更新嗎？ 有網路時打開就會自動更新，首頁底下有版本號。
