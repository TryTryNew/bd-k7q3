凱瑞系統譯本（教會用語）穆斯林說法

右邊的 ▶ 依「預設播放」唸。點一列展開：▶ 預錄（微軟孟加拉語男聲，沒網路也能播）、▶ 當地（播放當地人錄的）、🎙 請當地人錄下正確發音、🔊 手機內建語音。注音和拼音都是近似值，請以當地人發音為準。

使用說明

版本：對照筆記 v2（離線版，r1）

加到主畫面（離線使用）

  1. 有網路時先打開這個網頁一次，等它載入完成。
  2. iPhone：用 Safari 打開 → 下方「分享」→「加入主畫面」。
  3. Android：用 Chrome 打開 → 右上「⋮」→「加到主畫面」或「安裝應用程式」。
  4. 之後從主畫面圖示打開，沒有網路也能看。

手機語音沒有孟加拉語？

  • Android：設定 → 搜尋「文字轉語音」→ 偏好引擎選 Google →「安裝語音資料」→ 下載「孟加拉語」。下載後離線也能唸。
  • iPhone：可能沒有孟加拉語語音。請改用「🎙 錄音」，請當地弟兄姊妹唸給你錄。

真人錄音

  • 錄音只存在這支手機的這個網頁裡，不會上傳。
  • 第一次錄音時手機會詢問麥克風權限，請按「允許」。
  • 想把錄音給家人：按「匯出錄音」存成一個檔案，用 LINE 等傳給對方，對方在這頁按「匯入錄音」。
  • 從主畫面圖示打開和從瀏覽器打開，錄音可能各自分開存放，建議固定用主畫面圖示。
